# Франшиза АвтоМастер24 — займи свой город

Отдельная страница-предложение для кандидатов в представители города. На сайте платформы не размещается — ссылку отправляет владелец вручную.

- Сайт: https://avtomaster24bot-lab.github.io/avtomaster-franshiza/
- Персональная ссылка: `...?city=Караганда` — город подставляется в заголовок, кнопки и текст заявки.

## Где менять цифры и условия
Только файл `js/config.js` (объект `window.FRANCHISE`): цены по типам городов, окупаемость, роялти, условия, параметры примера расчёта.
Все цифры — примерные. `showFigures: false` скрывает цифры и показывает «Стоимость и условия — обсуждаются индивидуально».
